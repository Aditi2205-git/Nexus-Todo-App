# Nexus Tasks

A modern task management web app with a futuristic interface and simple productivity features.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by All, Active and Completed
- Track total, active and completed tasks
- View task completion progress
- Tasks remain saved after refreshing the page using Local Storage
- Responsive design for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
